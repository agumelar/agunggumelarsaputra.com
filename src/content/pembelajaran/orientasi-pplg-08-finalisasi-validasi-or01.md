# Finalisasi & Validasi Evidence Skill Passport OR-01

Selamat! Kalian telah tiba di **Puncak Sprint 1 (Pertemuan 8)**. Seluruh rangkaian pembelajaran Wawasan Dunia Kerja dan Profesi PPLG akan divalidasi secara resmi hari ini.

Dua karya utama yang telah kalian siapkan akan disatukan menjadi **Paket Portofolio Evidence OR-01** untuk menentukan perolehan Level Skill Passport pertama kalian di SMKN 1 Rongga.

## 🎯 Rubrik Resmi Penilaian Skill Passport OR-01

| Aspek Penilaian | Level 1 (Mengenal) | Level 2 (Mencoba ★ Target) | Level 3 (Mandiri) | Level 4 (Mahir / Portofolio) |
| :--- | :--- | :--- | :--- | :--- |
| **Kelengkapan Profesi** | Memuat < 3 profesi, deskripsi sangat minim. | Memuat minimal 5 profesi lengkap dengan deskripsi tugas & tools. | Memuat 6-8 profesi lengkap, rapi, dan terstruktur hierarkis. | Memuat 8 profesi lengkap + data gaji riil & studi kasus industri nyata. |
| **Rencana Minat Diri** | Rencana minat kosong atau hanya 1 kalimat. | Rencana minat terisi dengan alasan dan pilihan profesi jelas. | Rencana terinci dengan roadmap tahunan dan analisis kelebihan diri. | Sangat mendalam, menyertakan portofolio target dan rencana sertifikasi BNSP. |
| **Kualitas Visual & Keterbacaan** | Tidak teratur, teks sulit dibaca, berantakan. | Terbaca jelas, tata letak standar, menggunakan warna pembeda. | Estetika tinggi, ikon/grafik tepat guna, navigasi visual nyaman. | Kualitas desain setara infografis profesional, siap dipamerkan di publik. |
| **Aksesibilitas Evidence** | Link GDrive terkunci (*Access Denied*) / File salah. | Link terbuka (*Public Viewer*), nama file sesuai konvensi standar. | Link terorganisir di folder rapi beserta dokumen pendukung lengkap. | Struktur folder sempurna dengan dokumentasi refleksi dan log belajar. |

## 📋 Konvensi Penamaan File Evidence OR-01

Pastikan kedua file kalian dinamai sesuai format resmi berikut sebelum diunggah:
1. `[NIS]_[NamaLengkap]_OR-01_MindMapProfesi.pdf`  
   *(Contoh: `252610001_AhmadFauzi_OR-01_MindMapProfesi.pdf`)*
2. `[NIS]_[NamaLengkap]_OR-01_RencanaMinat.pdf`  
   *(Contoh: `252610001_AhmadFauzi_OR-01_RencanaMinat.pdf`)*

---

## 📝 Lembar Kerja Peserta Didik (LKPD P8)

Lakukan pemeriksaan mandiri (*Pre-Flight Checklist*) sebelum mengumpulkan link ke guru:

- [ ] File Mind Map sudah diekspor ke format PDF resolusi tinggi (tidak buram saat di-zoom).
- [ ] File Rencana Minat sudah ditandatangani/dilengkapi identitas lengkap.
- [ ] Pengaturan berbagi Google Drive disetel ke: **"Anyone on the internet with this link can view"** (Siapa saja yang memiliki tautan dapat melihat).
- [ ] Tautan sudah dicoba dibuka melalui *Private/Incognito Window* browser dan berhasil tampil tanpa login.
